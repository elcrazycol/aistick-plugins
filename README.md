# aistick-plugins

Плагины для [AIstickC](https://github.com/elcrazycol/AIstickC) — голосового
ассистента на M5StickC PLUS2.

Стик тянет `index.txt` из этого репозитория: потряси его → **Настройки** →
**Плагины**. В панели видно, что уже стоит, что можно обновить, и что поставить.
Прошивку пересобирать не нужно.

## Что тут лежит

| Плагин | Что делает |
|---|---|
| `switch.ais` | выключатель Tuya через прокси (канал 1/2/3/`all`) |
| `lamp.ais` | лампа на GPIO26 |
| `weather.ais` | погода на сегодня с `wttr.in` (без ключа) |
| `show_text.ais` | показать текст на экране стика |
| `web_search.ais` | поиск в интернете: свежие факты, которых модель не знает |

## Формат

`index.txt` — манифест: блоки через пустую строку, строки «ключ = значение».

```
name = switch
description = Включить, выключить или переключить выключатель
params = channel=1|2|3|all, state*=on|off|toggle
file = switch.ais
version = 1
```

| Ключ | Что это |
|---|---|
| `name` | имя функции для модели, латиницей |
| `description` | по нему модель решает, когда звать |
| `params` | описание аргументов; `*` — обязательный |
| `file` | имя файла скрипта рядом с манифестом |
| `version` | число; если больше установленного, панель пишет «обновить» |

Сам плагин — файл `.ais`: шапка из комментариев `#` с метаданными и тело на
крошечном языке (числа, строки, `if`/`else`, `while`, вызовы хозяина).

```
# name: show_text
# description: Показать короткий текст на экране стика.
# params: text*
# label: показываю текст

show(text)
```

`label` — короткая надпись на экране, пока плагин работает. Без неё
показывается имя плагина.

Доступные функции: `show`, `answer`, `ask`, `http`, `proxy_post`, `gpio`,
`gpio_get`, `json`, `len`, `str`, `num`, `contains`, `log`, `sleep`.
Подробнее — в разделе «Плагины» основного README.

## Как добавить свой

1. Положите рядом с `index.txt` файл скрипта и допишите блок в манифест.
2. Поднимите `version`, если плагин уже стоит у кого-то.
3. `git push` — панель на стике увидит обновление при следующем входе.

Свой репозиторий подключается одной строкой в `config.h`:

```c
#define PLUGIN_REPOS "https://raw.githubusercontent.com/<user>/<repo>/<branch>/index.txt"
```
